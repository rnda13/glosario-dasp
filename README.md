# glosario-dasp
glosario para el modulo de DASP


Digitalización:
Paso de información y procesos analógicos (papel, tareas manuales) a formato digital. Es el primer paso técnico, sin cambiar necesariamente la forma de trabajar.

Transformación Digital:
Cambio profundo de una organización (procesos, cultura y modelo de negocio) mediante el uso estratégico de tecnologías digitales para ser más eficiente y competitiva. Va más allá de digitalizar: implica cambiar cómo se opera.

IT (Tecnologías de la Información):
Sistemas que gestionan datos e información: ordenadores, redes, servidores, software, bases de datos y aplicaciones de gestión (correo, ERP, nube).

OT (Tecnologías de la Operación):
Sistemas que controlan y supervisan procesos físicos y maquinaria: PLC, SCADA, sensores, actuadores y equipos industriales.

Convergencia IT/OT:
Integración de los sistemas de información (IT) con los de operación (OT) para compartir datos entre la fábrica y la gestión de la empresa. Permite decisiones basadas en datos en tiempo real, aunque aumenta los riesgos de ciberseguridad.

Automatización Industrial:
Uso de tecnología (robots, PLC, sensores, software de control) para que los procesos de producción funcionen con mínima intervención humana, ganando velocidad, precisión y seguridad.

Internet de las Cosas (IoT / IIoT):
Red de objetos físicos con sensores y conexión a internet que recogen y envían datos. IIoT (Industrial IoT) es su aplicación en la industria: máquinas conectadas para monitorizar, predecir averías y optimizar la producción.

Infraestructura Tecnológica:
Conjunto de recursos técnicos que sostienen los servicios digitales de una empresa: hardware, redes, servidores, centros de datos, almacenamiento, software base y servicios en la nube.

Modelo de Negocio Digital:
Forma en que una empresa crea, ofrece y obtiene ingresos usando tecnologías digitales como pilar central (por ejemplo, plataformas, suscripciones, comercio electrónico o servicios basados en datos).
